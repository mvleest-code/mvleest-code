# Hi, I'm Mark van Leest

I help developers and partners get integrations working.

My background is in technical onboarding, troubleshooting and explaining
integrations with existing APIs. I am most at home where partner questions,
HTTP traffic, logs, documentation and product behaviour meet.

I work with REST APIs, OAuth 2.0, SSO/OIDC, SCIM, webhooks and server-sent
events. I also create practical examples with Postman and Python/Flask, and I
have hands-on experience diagnosing HLS/RTSP video, FFmpeg and network issues.

What I enjoy most is taking an unclear integration problem, reproducing it,
finding the actual failure point and turning the result into guidance that
other people can use.

## Selected work

- [Joplin Note Search for Ulauncher](https://github.com/mvleest-code/UL-JoplinNoteSearch)
  is a small integration with the Joplin Web Clipper API. It includes token-aware
  logging, user-facing error handling and practical troubleshooting guidance.
- [Video API v2 support samples](https://github.com/mvleest-code/EEVMS_APIv2_public)
  are older examples I used while testing and supporting an existing video API.
  They cover device I/O, recordings, snapshots and status events and are
  retained as reference material.
- [API articles and examples](https://mvleest-code.github.io/) brings together
  technical material about authentication and integration scenarios. Individual
  pages and linked repositories identify their respective authors and owners.
